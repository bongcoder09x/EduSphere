Certificate verification

Every certificate issued carries a code and a QR. Enter the code to check it against the issued register. Sample: EDS-2026-0142.

Verify a certificate

What is checked

The code is matched against the issue register: holder name, certificate type, issue date and status. Tampered or reissued certificates return no match.
